# Header & Footer Code for EmDash

Add Google Analytics, Tag Manager, pixels, verification tags or any code to your site's head or body, from the admin. No theme editing.

- **Any code, anywhere**: head, start of body, end of body. Everywhere, home page only, or addresses starting with a path.
- **Common tags by ID**: Google Analytics, Google Tag Manager, Meta Pixel, Microsoft Clarity.
- **Site verification**: Google Search Console, Bing, Pinterest, Yandex, Facebook. Served in the page head by the site itself.
- **On, off, edit, delete.** The Setup tab tells you whether the site is loading the code.

One-time setup: paste the short block from the Setup tab into the head of your base layout.
