## What is it for?

Every site needs small pieces of code that are not part of the theme: Google Analytics, Tag Manager, a Meta Pixel, a verification tag, a chat widget, a bit of CSS. This plugin lets you add them from the admin, choose where they go, and switch them on or off, without opening theme files.

## Where can code go?

Head, start of body, or end of body. Each snippet can show everywhere, only on the home page, or only on addresses that start with a path such as `/blog`.

## Do I need to know code for Google Analytics or a pixel?

No. The Common tags tab asks only for the ID and writes the code for you: Google Analytics, Google Tag Manager, Meta Pixel and Microsoft Clarity.

## How do verification tags work?

Pick the service, paste the code or the whole meta tag, done. The tag is served in the page head by the site itself, so Google Search Console or Bing can see it straight away. The Setup line is not needed for these.

## Can I turn something off without deleting it?

Yes. Turn off keeps the code and stops it running. Turn it on again any time.

## Is there a limit?

Up to 200 snippets, 20,000 characters each. More than any site needs.
